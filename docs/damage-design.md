# 穩當路試：車損系統設計

目的：讓碰撞看起來像真的碰到了車，而不是只有輪子或車頂突然掉下來。一般正常開不該被罰；只有明顯的重撞才會留下痕跡、影響操控，或把車子開報廢。

車體精靈維持原造型，不加廠徽或文字。

## 損傷分區

以車身局部座標為準（車頭朝 +x）：

| 分區 | 範圍（約） | 代表部位 |
| --- | --- | --- |
| `front` | x ≳ 0.9 | 前保桿、引擎蓋 |
| `rear` | x ≲ −0.9 | 車尾 |
| `roof` | y ≳ 0.35 | 車頂、擋風玻璃上緣 |
| `side` | 其餘車身中段 | 車門與側裙（側視只能看到靠近鏡頭的一側） |
| `wheelF` / `wheelR` | 對應車輪夾具 | 輪胎與輪圈 |
| `suspF` / `suspR` | 車輪接觸但帶側向／懸吊方向 | 避震與三角架 |
| `engine` | 由前 ple 重擊「滲透」而來，不單獨吃地面摩擦 | 動力系統 |

貨物與車斗的接觸不算車損，避免陶罐在斗裡晃就刮花車身。

## 撞擊位置與衝量如何對應損傷

在既有的 `post-solve` 裡讀取接觸衝量與世界接觸點，轉到車身局部後歸入上表分區。

- 免疫期（開場約 0.9 秒）不計傷，避免出生落下被算一次。
- 只處理「車子 vs 地面／道具」的接觸。車輪正常滾動的持續衝量要濾掉：需超過門檻才開始累積。
- 每個分區有短暫冷卻（約 0.12 秒），同一下彈跳不會連打好幾幀把傷害疊滿。
- 換算：`Δ = max(0, (impulse − I0) / Ispan)^1.2 × 權重`，寫入該區 0–1 的損傷值。
- 門檻 `I0` 必須高於腳本／一般玩家過彎、過 decel、普通落差的最大衝量，讓「正常開」最多只有極淡的痕跡，通常完全沒傷。
- 實測：腳本 12 關最大衝量約 10，因此 `I0` 取 18。撞上終點牆約 37，會留下可見刮痕，但不會掉件或報廢。一次約 60–80 的重撞會凹進去；車輪脫落仍要到既有的 95。
- 前 ple 重擊（impulse 明顯高於 I0）會按比例滲到 `engine`（約 40%），側撞滲一點到鄰近懸吊。
- 既有規則保留：車輪脫落仍只看車輪撞擊衝量（`BREAK_WHEEL_IMPACT`），不用懸吊彈簧反力；車頂脫落仍看焊點反力（`BREAK_PART`）。分區損傷到達臨界時，也可觸發同一套脫落流程。

階段（每區，也用來決定整車狀態）：

| 階段 | 分區值 | 表現 |
| --- | --- | --- |
| 完好 | 0–0.25 | 無可見損傷 |
| 輕微 | 0.25–0.50 | 刮痕 |
| 凹陷 | 0.50–0.75 | 該側精靈變形／凹陷貼圖，玻璃可能裂 |
| 嚴重 | 0.75–0.92 | 冒煙、操控受影響 |
| 臨界 | ≧ 0.92 | 零件可脫落；引擎可能熄火、冒火星 |

整車狀態取加權平均，脫落件另外加重。

## 視覺階段

全部疊在原車身／車輪精靈上，不換車、不寫字、不加廠徽。

1. **刮痕**：離屏快取畫布上的深色細線，只在損傷值變化時重畫。
2. **凹陷／變形**：把車身精靈切成數條，在受創一側做輕微擠壓與錯位（mesh warp）；再疊一層暗色凹痕。低畫質可只留貼圖、不做 warp。
3. **裂玻璃**：前窗區域畫不規則裂紋，半透明深色。
4. **煙**：從引擎蓋附近冒出灰煙粒子（引擎或車頭進入「嚴重」）。
5. **火星／火**：臨界或報廢時在車頭閃火星，短暫火光。低畫質只留稀薄的煙、不發火。

快取鍵包含各區損傷階與是否掉件，避免每幀重繪貼圖。

## 可脫落零件

- **前保桿**：`front` 到臨界，或單次極高衝量。從車頭生成獨立動態體，帶短促的分離速度，然後自由掉落。
- **車頂**：沿用現有焊點；分區 `roof` 到臨界也可拆。
- **車輪**：沿用現有撞擊衝量規則；該輪損傷到臨界且衝量夠大時拆。
- 脫落件計入 `brokenCount`，與現有「零件掉了」同一套。

## 操控影響

只在該區進入「嚴重」之後才開始，避免輕刮就改手感。

- **彎懸吊**：該側避震損傷造成持續的微小轉向力矩（車身被往該側拉或傾），幅度有上限。
- **傷輪**：降低該輪摩擦，並在馬達速度上加一點抖动，看起來會晃、抓地變差。
- **引擎損傷**：最大驅動扭力隨損傷下降（嚴重時最多約砍半），引擎聲改為斷續的熄火／爆氣（既有引擎迴圈加增益抖動，必要時再補短音效）。

報廢或兩輪都掉之後，基本開不動，只剩滑行。

## 報廢門檻（關卡失敗）

滿足任一項，即進入報廢，約 0.55 秒後 `finishRun(false, "車子報廢了")`，走既有失敗流程（結算、再試、獎勵重試），期間煙與火星要看得見：

- 整車加權損傷 ≥ 0.92；
- 兩輪都已脫落；
- 前保桿已掉，且引擎與至少一輪都到臨界。

免疫期內不報廢。報廢優先於過關判定。

## HUD 損傷指示

在左上資訊卡裡加一列「車況」，不另開會擋視線的大面板。宣傳擷取（`?promo=1`）仍隱藏整個 HUD。

- 文字：完好／輕微／受損／嚴重／報廢。
- 短進度條，顏色由綠到琥珀到紅。
- 右側一組小點，對應頭、尾、頂、側、兩輪，點的填色反映該區階段，讓玩家對得上撞到哪。

字型沿用既有中文 fallback，避免再出現缺字。

## 與星星的關係

- **三星**：在三星時間內到達，貨物關須保住陶罐，且沒有任何脫落零件。輕微刮痕、淺凹不扣星。
- **二星**：在二星時間內到達且（貨物關）陶罐還在；允許掉零件或嚴重損傷，但不能報廢。
- **一星**：到達但逾時。
- **零星／失敗**：陶罐摔破或掉出（現有規則），或車子報廢，或掉出跑道、逾時未到。

也就是：正常開到的 Cosmetics 不罰；把零件撞掉會失去第三顆星；把車子撞爛則直接失敗。

## 效能與低畫質

預算：中階手機直式 / 橫式維持約 60 fps，沿用既有 `fxQuality` 自動降級。

- 貼圖與 warp 只在損傷鍵變化時重繪一次，離屏畫布約等於精靈原尺寸。
- 高畫質：warp + 刮痕 + 裂紋 + 煙 + 臨界火星。
- 中畫質：不做 warp，粒子減半。
- 低畫質：簡刮痕、不裂紋或單條裂紋、煙更稀、無火星、不增加 dpr。
- 接觸處理本來就在 `post-solve`，每幀只做分區與累加，不做像素級查詢。

## 公平性

- 門檻以 `beatAll` 腳本與一般過關衝量為下限，再留餘裕。腳本必須 12／12 全三星，且不累積到會扣星或報廢的損傷。
- 開場免疫、分區冷卻、貨物接觸不計傷，避免「輕碰也碎」。
- 不改關卡幾何、重力、馬達基準值；操控懲罰只在嚴重損傷後出現。
- 若實測腳本會誤傷，先調門檻與冷卻，不給腳本開無敵。
